# Peek Suite

Peek Suite installs, updates and opens the Peek apps:

- **Peek File Explorer**: see what's really inside your files.
- **RePeek**: instant replay for your screen.

## Download

**[Download Peek Suite Setup](https://github.com/ronanrenders/peek-suite/releases/latest/download/Peek.Suite.Setup.exe)**

Run it, then pick the apps you want. Peek Suite keeps them up to date.

Windows 10 (version 2004) or newer. No admin rights needed.

> Windows may show a "Windows protected your PC" warning the first time, because
> Peek Suite isn't signed yet. Click **More info**, then **Run anyway**.
