# Peek Suite

Peek Hub installs, updates and opens the Peek apps:

- **Peek File Explorer**: see what's really inside your files.
- **RePeek**: instant replay for your screen.

## Download

**[Download Peek Hub Setup](https://github.com/YOUR-GITHUB-NAME/peek-suite/releases/download/hub-1.0.0/Peek.Hub.Setup.exe)**

Run it, then pick the apps you want. Peek Hub keeps them up to date.

Windows 10 (version 2004) or newer. No admin rights needed.

> Windows may show a "Windows protected your PC" warning the first time, because
> Peek Hub isn't signed yet. Click **More info**, then **Run anyway**.
